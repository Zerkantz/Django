# Tienda Online - Django REST API

Proyecto desarrollado en Django y Django REST Framework con autenticación JWT.

## Requisitos previos

- Python 3.10+
- MySQL / SQLite

## Instalación

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Zerkantz/Django.git
   cd Django
   ```

2. Crear y activar el entorno virtual:
   ```bash
   python -m venv venv
   # En Windows:
   .\venv\Scripts\activate
   ```

3. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```

4. Aplicar migraciones y ejecutar servidor:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
